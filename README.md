# Roblox Finder

A web app for discovering Roblox experiences, users, items, avatars, and groups.

## Planned features

- Search Roblox games, users, catalog items, avatars, and groups
- Popular games and recent searches
- Favorites
- Dark theme
- Shareable profile and item links

## Planned stack

- Next.js
- TypeScript
- Tailwind CSS
- Server-side API routes for Roblox API requests

## Status

Project setup is in progress. Features and API integrations will be added incrementally.
